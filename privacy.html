Galaxy.FM Privacy Policy

Last updated: August 2026

1. Data Collection

Galaxy.FM collects minimal data. We store your music library, playlists, and preferences locally in your browser using localStorage and IndexedDB. No personal data is transmitted to our servers.

2. YouTube API

Galaxy.FM uses the YouTube Data API v3 to search for music. By using Galaxy.FM, you agree to be bound by the YouTube Terms of Service. Google's Privacy Policy applies to YouTube API usage: https://policies.google.com/privacy

3. Data Deletion

You can delete all your data at any time by clearing your browser's localStorage and IndexedDB, or by using the "Clear all" options in the Galaxy.FM settings panel.

4. Third Party Services

Galaxy.FM uses the following third party services:

  • YouTube Data API v3 (Google) — for music search
  • Last.fm API — for album artwork
  • Cloudinary — for audio file storage
  • LRCLIB — for song lyrics
